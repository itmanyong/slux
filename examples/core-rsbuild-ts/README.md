# Core 示例（Rsbuild + 原生 TypeScript）

🧪 `@slux/core` 的交互式示例站：左侧按公开 API 分组，右侧以瀑布流卡片逐条演示，底部汇总本次运行的统计。示例逻辑来自与框架无关的共享层 [`examples/_kit`](../_kit/README.md)，本应用只负责布局与 DOM。

## 页面结构

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏：品牌 · /core · 主题切换                            │
├──────────────────────────────────────────────────────────┤
│ 页首：标题 · 一句话说明 · 右下角落款                      │
├──────────────┬───────────────────────────────────────────┤
│ API 索引      │ 当前分组标题 + 卡片数 + 重置               │
│ all          │                                           │
│ signal       │   卡片  卡片  卡片      ← 多列瀑布流        │
│ computed     │   卡片  卡片  卡片                        │
│ effect       │   卡片  卡片                              │
│ batch        │                                           │
│ scope        │                                           │
├──────────────┴───────────────────────────────────────────┤
│ 统计总览：公开 API / 示例 / 分组 ｜ 本次运行的各类记录数   │
└──────────────────────────────────────────────────────────┘
```

🗂️ 每张卡片分为三段：

| 🗂️ 区段   | 内容                                                                  |
| --------- | --------------------------------------------------------------------- |
| `header`  | 序号、标题、API 标签、单卡重置                                        |
| `content` | 一句话说明、读数（指标 / 多行文本 / 列表 / 三段链路）、操作按钮与输入 |
| `footer`  | 「运行日志」与「源码」两个标签页，互斥切换，默认收起                  |

`footer` 的两个标签是**互斥**的：点开运行日志会收起源码，点开源码会收起运行日志，再点当前标签则整体收起。这样一张卡片最多只占用一个面板的高度，瀑布流不会被两份内容同时撑高。

## 视觉基调

🎨 结构遵循 Chakra UI 的设计语言：白底 + 冷灰细边界，层级靠灰度与留白划分；操作按钮用 outline / solid 两档，列表读数渲染成 soft badge 药丸，Tabs 用下划线选中态。在 Chakra 结构之上做了三处去模板化处理：

- **强调色用 Chakra teal**（`#319795` / 深色 `#4fd1c5`）而不是烂大街的蓝紫；实色底上的文字色由 `--on-accent` 按主题切换，保证对比度；
- **字体不用系统默认栈**：Space Grotesk（标题）+ IBM Plex Sans（正文）+ JetBrains Mono（代码与标签），经 `@fontsource` 本地打包，中文回退本机字体；
- **顶栏是深色 chrome 条**，浅色主题下也保持，让页面形成「深色导航 + 白色主体」的两段式结构；卡片入场有阶梯式浮现动画（`prefers-reduced-motion` 下自动压平）。

移动端把左侧索引折叠成横向标签，统计条回到文档流。

## 源码 = 最小复现片段

🧪 卡片「源码」面板展示的不是示例的脚手架实现，而是**其他开发者搬进自己项目即可复现同款效果的最小 API 用法**。每个示例在共享层旁有一份同名 `.repro.ts` 片段（如 `demos/signal/basic-write.repro.ts`），登记表 `src/ui/sources.ts` 在构建期通过 `?raw` 读取该文件，因此：

- 展示内容是一份真实存在的文件，不会与文档脱节；
- 片段由 `@slux/kit-example` 的 `repro` 测试真实运行，`console` 输出逐条与注释中的预期比对——注释里的每一行 `// →` 都是已验证的事实；
- 片段只含 slux API 调用与 `console.log`，不含 DOM、样式或框架代码；
- 面板顶部会显示该片段在仓库中的真实路径，可对照阅读。

新增示例后执行 `pnpm --filter @slux/example-core-rsbuild-ts gen:sources` 重新生成登记表。

## 示例覆盖

🧪 21 张卡片覆盖 7 个公开 API：

| 🧭 分组    | 卡片                                                                                                           |
| ---------- | -------------------------------------------------------------------------------------------------------------- |
| `signal`   | 基础写入与订阅、草稿提交与结构共享、Map/Set 草稿、自定义 `equals`、函数值与 `undefined`/`NaN`/`±0`、订阅与退订 |
| `computed` | 惰性求值与缓存、动态依赖、派生结果相等时跳过下游、循环依赖报错                                                 |
| `effect`   | 首次同步执行、清理函数时序、清理函数中的读取不构成依赖、多个 effect 的错误汇总为 `AggregateError`              |
| `batch`    | 批内合并通知、嵌套批处理与返回值、批处理不是事务                                                               |
| `scope`    | 作用域覆盖与全局读取、`fork` 动态继承（链路读数）、`serializeScope` 快照、作用域写入不触发全局订阅             |

## 运行

🚀 在仓库根目录执行：

```sh
pnpm install
pnpm --filter @slux/core... build
pnpm --filter @slux/example-core-rsbuild-ts dev
```

构建与检查：

```sh
pnpm --filter @slux/example-core-rsbuild-ts build
pnpm --filter @slux/example-core-rsbuild-ts typecheck
pnpm --filter @slux/example-core-rsbuild-ts lint
pnpm --filter @slux/kit-example test
```

示例行为由共享层的测试覆盖（`examples/_kit/__tests__`），测试直接调用示例的操作与读数，不依赖 DOM。

## 目录结构

```
src/
  index.ts            入口：菜单筛选、瀑布流渲染、主题与统计联动
  index.html          页面骨架
  index.css           样式入口（拆分在 styles/ 下）
  styles/
    tokens.css        颜色、字体、尺寸变量（浅色 / 深色）
    base.css          基础重置与排版
    layout.css        顶栏、页首、左右布局、瀑布流、统计总览
    card.css          卡片三段结构与运行日志
    code.css          源码面板与着色
  ui/
    page.ts           页面骨架与节点引用
    card.ts           单卡片的实例生命周期、读数渲染、日志与源码面板
    masonry.ts        多列瀑布流（按测量高度放入最短列）
    sources.ts        源码登记表（?raw，由 scripts/gen-sources.mjs 生成）

    stats.ts          会话统计
    theme.ts          主题持久化
scripts/
  gen-sources.mjs     扫描共享层示例文件，生成源码登记表
```

## 交互说明

- 💡 左侧目录切换分组；卡片状态在切换分组时保留，重置只作用于当前可见卡片。
- 「重置本组」先释放旧订阅与 effect，再按初始状态重建卡片。
- 运行日志用一个小圆点标记语气（写入 / 通知 / 副作用 / 计算 / 作用域 / 错误），正文保持中性色，只有错误会连正文一起标红；底部统计同步累计。
- 「源码」面板可横向滚动，右上角可一键复制原文。
- 主题选择写入 `localStorage`；首次访问跟随系统偏好。

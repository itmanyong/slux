| 示例                         | 可以验证什么                                               |
| ---------------------------- | ---------------------------------------------------------- |
| [响应式核心](/examples/core) | `signal`、`computed`、`effect`、`batch` 与作用域如何协作。 |
| [共享工具](/examples/shared) | 多个状态模块共用的工具能力如何在应用中使用。               |

需要在同一页面切换其他层的示例，可前往[示例总览](/examples/)。

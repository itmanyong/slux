| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| 范式层   | [集中式状态](/examples/store)、[原子状态](/examples/atom)、[对象代理](/examples/proxy)、[Flux 数据流](/examples/flux)、[状态机](/examples/state-machine)、[RxJS 桥接](/examples/rxjs)                                                                                                                                                        |

## 交互式示例总览

使用右上角的选择框切换示例，或展开目录按层级浏览。总览内的示例会隐藏各自顶栏；需要完整页面时，可使用总览顶栏的“在新窗口打开”。

<ExampleFrame title="slux 全部示例交互总览" src={normalizeImagePath("/examples/_gallery/")} sourcePath="examples/_gallery" />

示例页与各包的“演示示例”线路运行同一份构建产物。独立项目需要先构建；本地开发可运行 `pnpm --filter @slux/website docs:examples` 更新嵌入资源。

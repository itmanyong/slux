# 范式层总览

范式层提供不同的状态组织方式。选择与你的状态规模、更新方式和现有代码最接近的示例进行体验。

| 示例                              | 关注点                           |
| --------------------------------- | -------------------------------- |
| [集中式状态](/examples/store)     | 将状态与操作集中到一个 store。   |
| [原子状态](/examples/atom)        | 以较小的状态单元组织数据。       |
| [对象代理](/examples/proxy)       | 通过对象属性读写驱动更新。       |
| [Flux 数据流](/examples/flux)     | 按单向数据流组织事件与状态。     |
| [状态机](/examples/state-machine) | 用明确的状态和转换表达交互流程。 |
| [RxJS 桥接](/examples/rxjs)       | 将响应式流接入 slux 状态。      |

可在[示例总览](/examples/)中连续切换这些示例，比较交互方式。

# AI

🤖 文档站为每个页面提供“复制 Markdown”操作，并在构建产物中生成 <a href={normalizeImagePath("/llms.txt")}>llms.txt</a> 与 <a href={normalizeImagePath("/llms-full.txt")}>llms-full.txt</a>。向 AI 工具提问时，优先提供与你使用的包对应的文档，而不是只提供包名。

例如，要在 React 中接入状态，可以附上 [React 使用指南](/packages/react/)和 [Core API](/packages/core/api)，并描述现有组件与状态更新方式。涉及运行时函数签名时，查阅对应包的“API 定义”；涉及 TypeScript 类型时，查阅“类型定义”；涉及真实交互时，查阅“演示示例”。

🧪 AI 生成的代码应对照当前安装版本的公开导出项，并在项目中运行类型检查。各包 README 原文也可通过包页顶部切换查看。

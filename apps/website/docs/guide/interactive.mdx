# 交互式示例

下方示例使用 `@slux/core` 创建状态源，再用 React 的外部 store 接口订阅。预览展示运行结果；Playground 可修改代码并观察变化。安装时需同时提供 `@slux/core` 的 peer 依赖 `limu`。

## 组件预览

```tsx preview
import { useSyncExternalStore } from "react";
import { signal } from "@slux/core";

const count = signal(0);

export default function Counter() {
  const value = useSyncExternalStore(count.subscribe, count.get, count.get);
  return <button onClick={() => count.set(value + 1)}>已点击 {value} 次</button>;
}
```

在 React 应用中通常直接使用 [@slux/react 的 `useSignal`](/packages/react/)。这里展开订阅过程，便于看清 core 与 UI 框架的边界。

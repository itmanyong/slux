# 开始使用

slux 把响应式核心、状态范式、框架绑定和 Store 中间件拆成独立包。先安装你直接导入的包，再按需要组合。

## 安装核心

```sh
pnpm add @slux/core limu
```

## 创建第一个状态

```ts
import { computed, effect, signal } from "@slux/core";

const count = signal(1);
const doubled = computed(() => count.get() * 2);

const stop = effect(() => console.log(doubled.get())); // 首次输出 2
count.set(2); // 同步输出 4
stop();
```

`signal` 保存可写值；`computed` 根据读取的状态惰性计算；`effect` 订阅依赖并返回清理函数。

`limu` 是 `@slux/core` 的必需 peer。涉及 `Map` 假值键的 draft 更新时，还需按[仓库补丁说明](https://github.com/itmanyong/slux/blob/main/patches/README.md)处理。

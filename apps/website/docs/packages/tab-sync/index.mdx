# 跨标签页同步

<p className="package-lead">通过 BroadcastChannel 同步多个标签页的 Store 状态。</p>

## 适用场景

同一应用在多个标签页打开，需要同步状态。

## 安装

```sh
pnpm add @slux/store @slux/tab-sync @slux/core limu
```

安装命令列出下面示例直接导入的包。实际发布状态与线上版本请以包管理器查询结果为准。

## 开始使用

```ts
import { createStore } from "@slux/store";
import { broadcast } from "@slux/tab-sync";

type State = { theme: string; count: number; increment: () => void };

const store = createStore<State>(
  (set) => ({
    theme: "light",
    count: 0,
    increment: () => set((state) => ({ count: state.count + 1 })),
  }),
  {
    middleware: [
      broadcast<State>({
        channel: "app-state",
        // 只发送数据字段，action 函数无法通过结构化克隆
        filter: (state) => ({ theme: state.theme, count: state.count }),
      }),
    ],
  },
);

store.setState({ theme: "dark" });
```

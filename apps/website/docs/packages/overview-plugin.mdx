# 插件总览

目前插件层没有独立发布的包。若项目使用 `unplugin-auto-import`，可通过各包公开的 `createAutoImportApis` 生成自动导入配置。

| 接入方式         | 文档                                      |
| ---------------- | ----------------------------------------- |
| 自动导入公开 API | [自动导入接入指南](/packages/auto-import) |

不使用自动导入时，直接从所需的包显式导入 API。各包的 [API 定义](/packages/core/api)页面列出公开入口和用法。

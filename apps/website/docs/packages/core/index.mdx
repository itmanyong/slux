# 响应式核心

<p className="package-lead">在框架外管理可订阅状态，并组合派生值与同步副作用。</p>

## 适用场景

需要在多个框架之间共享状态逻辑，或要自己组织状态层。

## 安装

```sh
pnpm add @slux/core limu
```

安装命令列出下面示例直接导入的包。实际发布状态与线上版本请以包管理器查询结果为准。

`limu` 是 `@slux/core` 的必需 peer。需要 `Map` 假值键 draft 更新时，还需参照[补丁说明](https://github.com/itmanyong/slux/blob/main/patches/README.md)在应用项目中应用同一补丁。

## 开始使用

```ts
import { batch, computed, effect, signal } from "@slux/core";

const count = signal(0);
const doubled = computed(() => count.get() * 2);

// effect 首次同步执行，之后在依赖变化后同步重跑
const dispose = effect(() => {
  console.log(count.get(), doubled.get());
});
// 输出：0 0

// 批处理内的多次写入合并为一次通知/重跑
batch(() => {
  count.set(2);
  count.set((value) => value + 1);
});
// 输出：3 6

dispose(); // 释放副作用，幂等
```

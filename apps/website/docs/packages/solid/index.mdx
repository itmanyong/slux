# Solid 绑定

<p className="package-lead">把 slux 状态映射到 Solid Accessor。</p>

## 适用场景

Solid 组件需要订阅共享状态。

## 安装

```sh
pnpm add @slux/core @slux/solid solid-js limu
```

安装命令列出下面示例直接导入的包。实际发布状态与线上版本请以包管理器查询结果为准。

## 开始使用

```tsx
import { signal } from "@slux/core";
import { useSignal } from "@slux/solid";

const count = signal(0);
function Counter() {
  const value = useSignal(count); // Accessor<number>
  return <button onClick={() => count.set((n) => n + 1)}>{value()}</button>;
}
```

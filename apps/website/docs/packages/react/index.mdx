# React 绑定

<p className="package-lead">在 React 组件中订阅 slux 状态。</p>

## 适用场景

React 应用希望沿用已有 slux 状态实例。

## 安装

```sh
pnpm add @slux/core @slux/react react limu
```

安装命令列出下面示例直接导入的包。实际发布状态与线上版本请以包管理器查询结果为准。

## 开始使用

```tsx
import { computed, signal } from "@slux/core";
import { useSignal } from "@slux/react";

const count = signal(0);
const doubled = computed(() => count.get() * 2);

export function Counter() {
  const value = useSignal(count); // 0
  const double = useSignal(doubled); // 0
  return (
    <button onClick={() => count.set((current) => current + 1)}>
      {value} × 2 = {double}
    </button>
  );
}
```

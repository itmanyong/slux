# 核心总览

🧭 从 `@slux/core` 开始创建状态。它不依赖 UI 框架；需要组件订阅时，再安装对应的框架绑定。`@slux/shared` 提供包之间复用的基础工具。

| 📦 包          | 用途                       | 从这里开始                                                       |
| -------------- | -------------------------- | ---------------------------------------------------------------- |
| `@slux/core`   | 创建、派生和订阅响应式状态 | [使用指南](/packages/core/) · [API 定义](/packages/core/api)     |
| `@slux/shared` | 同步任务与自动导入辅助工具 | [使用指南](/packages/shared/) · [API 定义](/packages/shared/api) |

🧩 第一次接入可先阅读[快速开始](/guide/)，再根据应用的状态组织方式选择[范式](/packages/overview-paradigm)。

# Preact 绑定

<p className="package-lead">在 Preact 组件中订阅 slux 状态。</p>

## 适用场景

Preact 应用需要使用 slux 状态，又不想依赖 React。

## 安装

```sh
pnpm add @slux/core @slux/preact preact
```

安装命令列出下面示例直接导入的包。实际发布状态与线上版本请以包管理器查询结果为准。

## 开始使用

```tsx
import { signal } from "@slux/core";
import { useSignal } from "@slux/preact";

const count = signal(0);

export function Counter() {
  const value = useSignal(count);
  return <button onClick={() => count.set((n) => n + 1)}>{value}</button>;
}
```

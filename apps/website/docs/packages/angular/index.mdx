# Angular 绑定

<p className="package-lead">🔌 把 slux 状态接入 Angular Signal 或 Observable。</p>

## 适用场景

💡 Angular 组件或服务需要读取外部状态。

## 安装

```sh
pnpm add @slux/core @slux/angular @angular/core rxjs
```

📦 安装命令列出下面示例直接导入的包。实际发布状态与线上版本请以包管理器查询结果为准。

## 开始使用

```ts
import { Component } from "@angular/core";
import { signal } from "@slux/core";
import { toAngularSignal } from "@slux/angular";

const count = signal(0);

@Component({ selector: "app-counter", template: "{{ value() }}" })
export class Counter {
  readonly value = toAngularSignal(count);
}
```

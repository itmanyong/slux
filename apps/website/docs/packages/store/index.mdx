# 集中式 Store

<p className="package-lead">把关联数据与 action 放在同一个 Store，并按需接入中间件。</p>

## 适用场景

一个业务模块有成组状态、更新函数和订阅者。

## 安装

```sh
pnpm add @slux/store @slux/core
```

安装命令列出下面示例直接导入的包。实际发布状态与线上版本请以包管理器查询结果为准。

## 开始使用

```js
import { createStore } from "@slux/store";

const counter = createStore((set, get) => ({
  count: 0,
  increment: () => set({ count: get().count + 1 }),
  reset: () => set({ count: 0 }),
}));

const stop = counter.subscribe((state, prevState) => {
  console.log(`${prevState.count} -> ${state.count}`);
});

counter.getState().increment(); // 通知一次
counter.setState({ count: 5 }); // 通知一次
console.log(counter.getState().count);
stop();
counter.destroy();
```

## 接下来

createStore 返回 getState、setState、subscribe 等接口；中间件通过 options.middleware 接入。

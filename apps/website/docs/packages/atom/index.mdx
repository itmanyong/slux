# 原子状态

<p className="package-lead">以独立 atom 组织状态，按读取依赖组合派生值。</p>

## 适用场景

状态需要细粒度拆分，或者需要可组合的派生状态。

## 安装

```sh
pnpm add @slux/atom @slux/core
```

安装命令列出下面示例直接导入的包。实际发布状态与线上版本请以包管理器查询结果为准。

## 开始使用

```ts
import { atom, derived } from "@slux/atom";
import { batch } from "@slux/core";

const count = atom(0);
const doubled = derived((get) => get(count) * 2);

const stop = doubled.subscribe((value) => console.log(value)); // 不立即通知
count.set(2); // 通知 4
count.update((value) => value + 1); // 通知 6
console.log(doubled.get()); // 6

batch(() => {
  count.set(10);
  count.set(20);
}); // 批处理结束，订阅只收到最终值 40

stop();
```

## 接下来

atom 用于可写值，derived 用于只读派生；需要自定义写入时使用 writableAtom。

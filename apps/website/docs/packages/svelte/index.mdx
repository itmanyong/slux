# Svelte 绑定

<p className="package-lead">把 slux 状态包装为 Svelte store。</p>

## 适用场景

Svelte 组件希望使用原生 store 订阅语法。

## 安装

```sh
pnpm add @slux/core @slux/svelte svelte
```

安装命令列出下面示例直接导入的包。实际发布状态与线上版本请以包管理器查询结果为准。

## 开始使用

```svelte
<script>
  import { signal } from "@slux/core";
  import { toWritable } from "@slux/svelte";

  const count = toWritable(signal(0));
</script>

<button onclick={() => count.update((n) => n + 1)}>{$count}</button>
```
